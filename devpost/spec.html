⚡ The Mandatory Causal Chain (Changed Rule → Immediate Effect → Consequence)

To ensure genuine AI simulation rather than generic trivia, every consequence is forced through this 3-step reasoning chain:

STEP 1: RULE CHANGE
"Magic also works in darkness, but consumes memory."
Creator modifies rule in What-If Lab
→
STEP 2: IMMEDIATE EFFECT
Sunlight-exclusive monopoly collapses; midnight ambushes become lethal.
Direct physical & tactical law shift
→
STEP 3: ENTITY CONSEQUENCE
High Sun-Priestess Lyra loses sole authority; temple raided at midnight.
Targeted entity impact with explanation

POST /api/generate-world

Payload: { "premise": string } (min 10 chars)

Response: 200 OK with WorldModel (Overview, 3–4 Characters, 2–3 Factions, 2–3 Locations, 3–4 Rules).

POST /api/simulate-consequences

Payload: { "baselineWorld": WorldModel, "changedRuleId": string, "newRuleText": string }

Response: 200 OK with SimulationResult containing the 3-step causal chain for affected entities.

🛡️ Failure Modes & Fallback Guarantees

  • Missing GEMINI_API_KEY: Route immediately returns 500 error; UI alerts creator to check .env.local.
  • Malformed JSON Output: Server validates with validation.ts; returns 502 with clean diagnostic message.
  • Rate Limit (429) / Timeout: UI surfaces honest error banner with "Retry" button.
  • No Silent Fake Data: App strictly avoids injecting fake hardcoded responses disguised as live AI outputs.
